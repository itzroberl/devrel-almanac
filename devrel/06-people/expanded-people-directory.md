**Caveat throughout.** People change jobs constantly. Treat affiliations as snapshots requiring refresh, not as authoritative claims. Where someone is named and the affiliation has changed since publication, the name remains a useful pointer to a real and active practitioner.

## How to read this list

- **Don't try to memorise it.** Use it for discovery.
- **Verify current affiliation** before relying on any entry as authoritative.
- **Cross-reference with company-program directories** for current employees. The Microsoft MVP directory, AWS Heroes page, GDE directory, MongoDB Champions page, and so on are authoritative for current program membership.
- **Search LinkedIn and Bluesky / X** for current activity around any name.

## What this list omits

- **Most non-English-speaking senior practitioners.** A genuine global directory would require coverage that mostly happens in regional languages.
- **Internal-platform-engineering leaders.** Visible in their own ecosystems (Spotify Backstage maintainers, Netflix's productivity-engineering org, etc.) but largely separate from external-DevRel discourse.
- **Most non-AI-recent emerging talent in 2024–2026.** The field has had substantial turnover; new senior voices are continuously emerging.
