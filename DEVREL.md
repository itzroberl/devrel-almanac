# DEVREL: A Total Almanac of Developer Relations

> A comprehensive, cross-referenced reference covering the history, people, companies, conferences, tools, platforms, metrics, tactics, and trends that define Developer Relations (DevRel) as a discipline — from its 1980s origins through 2026.

This almanac is organized as a set of focused topic files. Start with the foundations, follow the cross-links, and dive deep wherever you need. Every file is a standalone read with its own bibliography of further reading.

## Methodology and sources

This almanac was assembled from a deep research pass across Perplexity, Google, and primary sources, supplemented by encyclopedic knowledge of the field through mid-2026. Each file lists its own primary references at the bottom. Where statistics or follower counts are quoted, they should be treated as approximate snapshots at time of writing — these numbers change quickly.

Key umbrella sources cited throughout:

- **SlashData**, *State of the Developer Nation* reports (twice yearly).
- **Stack Overflow Developer Survey** (annual, 2011–present).
- **GitHub Octoverse** (annual).
- **The Linux Foundation / Developer Relations Foundation** (founded August 2025).
- Books listed in [`devrel/12-resources/books.md`](devrel/12-resources/books.md).

## Contributing and corrections

This document is meant to be living. Treat names, headcounts, follower counts, and "current role" claims as snapshots that need refreshing each quarter. People in DevRel move companies often; programs are renamed, merged, or sunset.
